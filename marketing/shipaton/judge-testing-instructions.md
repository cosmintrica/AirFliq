# AirFliq — judge testing instructions

The private copy with the offer codes is `build/judge-access/devpost-judge-instructions-with-codes.txt` (gitignored).

```
AirFliq is a macOS menu bar utility (macOS 13 or later, Apple Silicon and Intel). It needs no account.

INSTALL
https://apps.apple.com/us/app/airfliq/id6801543708

PREMIUM ACCESS — choose either
1) Free 7-day trial: click the AirFliq icon in the menu bar → Lifetime Pro → "Start free 7-day trial". It is a free App Store product: it never renews and never charges.
2) Lifetime Pro for free (works beyond October 13): redeem a one-time code (supplied privately to judges) on macOS 15 or later.
   • Mac App Store → click your name (bottom left) → Redeem → enter the code, or open:
     https://apps.apple.com/redeem?ctx=offercodes&id=6801543708&code=CODE
   • Then open AirFliq → Lifetime Pro → Restore Purchase.
   • Each code works once and each Apple Account can redeem one; if a code was already used, take the next.
   • Version 1.0.1 (submitted to App Review) also adds a "Redeem Code" button inside the offer screen.

SETUP NOTES
• Setup can be finished without the Finder extension. To enable right-click: System Settings → General → Login Items & Extensions → scroll to Extensions → By App → ⓘ next to AirFliq → switch it on. Version 1.0.1 guides you through this and detects it automatically.
• On Macs managed by an organization, IT policies can block Finder extensions; the shortcut, menu bar and drag target still work.
• In version 1.0.0 the setup window can simply be closed; AirFliq keeps running in the menu bar.

WHAT TO TRY
1. Press the global shortcut (default ⌃⌥A), choose a file → Apple's native AirDrop panel opens.
2. Finder: right-click any file → Send with AirFliq.
3. Turn on "Drag target" in the menu, start dragging any file → the magnetic target appears beside the cursor. Drop the file on it (in 1.0.1 the card folds into a paper plane and flies off the screen).
4. Menu bar icon → Choose files to send…
You can cancel the AirDrop panel at any time; a completed transfer needs a nearby Apple device with AirDrop on.

FREE TIER (1.0.1): 5 sends per day forever, unlimited with the trial or Lifetime Pro. Prices are localized by the App Store.
```
