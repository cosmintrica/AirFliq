### 2/6

AirFliq starts where the file already is. Select it in Finder, use a global shortcut, right-click it, or drag it to a magnetic target. The destination flow remains Apple's native AirDrop experience.

#Shipaton

### 3/6

Permission design became a core feature. AirFliq uses Finder access and lets each person choose the folders it may use. It does not require blanket Full Disk Access. Fast can still be transparent.

#Shipaton

### 4/6

I rebuilt the small moments repeatedly: permission progress, shortcut selection, drag hover, drop confirmation, notifications, and recovery states. Public feedback exposed the rough edges that code alone did not.
